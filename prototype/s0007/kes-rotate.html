冷环境命令

复制命令到 cold environment 执行，生成 `node.cert` 后回到当前界面。

核心任务锚点：先复制命令，再离线执行。 
cardano-cli node issue-op-cert \
  --kes-verification-key-file kes.vkey \
  --cold-signing-key-file cold.skey \
  --operational-certificate-issue-counter-file opcert.counter \
  --kes-period <current-kes-period> \
  --out-file node.cert
Input: kes.vkey Input: opcert.counter Output: node.cert Run In: cold environment
将 `node.cert` 拖拽到这里

也可选择文件。文件通过校验后会自动流转到 Step 3，无需手点“下一步”。

1. File Detected 等待上传
2. Validating 校验证书格式 / 网络 / KES 匹配
3. Auto Continue 通过后进入 Step 3，提供 3 秒撤销窗口
错误文件使用非阻塞提示：在上传区下方显示错误原因（如“不是 node.cert”或“network mismatch”），并提供 查看修复建议。
