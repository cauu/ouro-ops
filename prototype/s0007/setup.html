First Launch Flow

No login required. Create your pool workspace once, then enter dashboard directly.

On app start, bootstrap checks whether a pool exists in local workspace. If not, users see this setup step. If yes, app navigates straight to dashboard.

  • Single-pool workspace initialization with safe defaults
  • No account registration and no remote auth dependency
  • After creation, all operations continue from dashboard
